# Moxie IT WordPress Assignment

## Requirements

- WordPress
- Node.js
- npm

## Installation

1. Copy the theme folder into `wp-content/themes`
2. Activate the theme
3. Run:

```bash
npm install
npm run build
```

## Completed Features

- Custom WordPress Theme
- Dynamic Header
- Dynamic Footer
- Customizer Settings
- Practice Area Custom Post Type
- Single Practice Area Template
- Native Gutenberg Practice Areas Block (React + block.json + PHP render callback)

## Required Plugins

- None currently
- Contact Form 7 (if used for Consultation Form Block)
